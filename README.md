An end-to-end customer churn prediction project using **Python**, **TensorFlow/Keras**, and **Machine Learning** to identify customers likely to discontinue a service, enabling businesses to take proactive retention measures.

# 📌 Project Overview

This project focuses on predicting customer churn using deep learning techniques. The goal is to build a binary classification model that identifies customers who are likely to discontinue a service, enabling proactive customer retention and data-driven business decisions.

The project follows an end-to-end data science workflow, including:

- Data Loading
- Exploratory Data Analysis (EDA)
- Data Cleaning & Manipulation
- Feature Engineering
- Deep Learning Model Development
- Model Evaluation

---

# 🎯 Business Problem

Retaining existing customers is significantly more cost-effective than acquiring new ones.

By analyzing customer demographics, service subscriptions, and payment behaviors, this project predicts customer churn, allowing businesses to identify high-risk customers and implement targeted retention strategies.

# 🧠 Deep Learning Model

The churn prediction model was built using a **Sequential Neural Network** in **TensorFlow/Keras**.

### Model Architecture

- Sequential Neural Network
- Multiple Dense Layers
- ReLU Activation Functions
- Sigmoid Output Layer
- Dropout Layers to reduce overfitting

### Objective

Predict whether a customer will:

- Stay
- Churn

---

# 📈 Key Insights

- Customer tenure has a significant impact on churn.
- Customers with month-to-month contracts are more likely to churn.
- Certain payment methods are associated with higher churn rates.
- Deep learning effectively captures complex, non-linear customer behavior patterns.
